# Лабораторна робота 3: Нездатні до змін структури даних (immutability) у Python

## Висновки про переваги та накладні витрати
Перехід на незмінні структури даних (`tuple`, `frozenset`, `@dataclass(frozen=True)`, `MappingProxyType`) забезпечує такі переваги:
- **Референтна прозорість**: результати функцій залежать лише від їх вхідних даних, що значно спрощує тестування.
- **Безпека та хешованість**: сутності (наприклад, `Order`) тепер можна безпечно використовувати як ключі у словниках або елементи множин (`set`).
- **Відсутність побічних ефектів**: зміни виконуються виключно через повернення нових копій об'єктів (pure updates).

**Накладні витрати**: 
Створення нових об'єктів при кожній зміні вимагає додаткових витрат пам'яті та процесорного часу порівняно з in-place мутаціями. Однак тести продуктивності (через `pytest-benchmark`) показують, що для більшості бізнес-задач цей оверхед є мінімальним і некритичним на фоні отриманої стабільності та передбачуваності коду.
